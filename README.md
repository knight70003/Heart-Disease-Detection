❤️ Heart Disease Detection Using Machine Learning

📌 Overview

This project is a Machine Learning based web application that predicts the possibility of heart disease using patient health parameters. The application helps in early prediction and analysis using trained ML models.

---

🚀 Features

- Heart disease prediction system
- User-friendly interface
- Real-time prediction
- Machine Learning model integration
- Fast and accurate results

---

🛠️ Technologies Used

- Python
- Streamlit / Flask
- Scikit-learn
- Pandas
- NumPy
- Pickle

---

📂 Dataset

The dataset used for this project contains medical attributes such as:

- Age
- Blood Pressure
- Cholesterol
- Heart Rate
- Chest Pain Type
- ECG Results

Dataset Source: UCI/Kaggle Heart Disease Dataset

---

🤖 Machine Learning Model

Model Used:

- K-Nearest Neighbors (KNN)

The model was trained and saved using ".pkl" files for deployment.

---

📸 Project Workflow

1. User enters medical details
2. Data preprocessing is performed
3. ML model predicts heart disease risk
4. Prediction result is displayed on screen

---

⚙️ Installation & Setup

git clone https://github.com/knight70003/Heart-Disease-Detection.git

cd Heart-Disease-Detection

pip install -r requirements.txt

python app.py
